## О продукте

**koshel** объединяет в одном месте:

- **расходы и доходы** — голос, скан чека, ручной ввод, AI-анализ месяца;
- **весь капитал** — акции, облигации, крипта, валюта, вклады с живыми курсами (MOEX, CoinGecko, ЦБ РФ);
- **подключения** — брокеры и банки через официальные API с согласия пользователя.

Наша цель — дать человеку **актуальную и цельную картину финансов**: не только «куда ушли деньги», но и «сколько у меня всего» — без ручного переноса данных между приложениями.

Приложение уже работает на iOS (Release-сборка), backend — Supabase, архитектура под Open Finance заложена.

## Уже есть интеграция с T‑Invest

Мы реализовали синхронизацию портфеля **T‑Invest** через read-only токен: позиции отображаются в разделе «Капитал», обновляются дивиденды и комиссии, пользователь видит динамику по MOEX.

Это показывает, что koshel — рабочий PFM, а не концепт. Следующий логичный шаг — **дебетовые карты и счета T‑Банка** через Open API / Open Finance, чтобы траты подтягивались автоматически.

## Что мы просим

Рассмотреть **пилотное партнёрство** для физических лиц:

1. OAuth-согласие пользователя на **read-only** доступ к операциям по счетам и картам;
2. Импорт транзакций за 90 дней + инкрементальная синхронизация;
3. Техническая поддержка на этапе пилота (sandbox / тестовый контур).

Мы готовы:

- пройти процедуру партнёрской интеграции;
- соблюдать требования безопасности (токены только на сервере, явный отзыв согласия, 152‑ФЗ);
- предоставить демо, документацию по архитектуре и ограниченный пилот на реальных пользователях.

## В чём ценность для T‑Банка

Мы видим win-win модель, а не «односторонний доступ к данным»:

**1. Продвижение продуктов в контексте**  
Когда у пользователя накопилась свободная сумма или низкий индекс финансового здоровья, koshel может **рекомендовать вклады, накопительные счета и другие продукты T‑Банка** с актуальными ставками — в момент, когда человек думает о деньгах.

**2. Cross-sell под реальное поведение**  
Аналитика трат (категории, MCC) позволяет предлагать релевантные продукты: кэшбэк-карты под частые категории, кредитные лимиты — только с согласия пользователя и в рамках согласованных правил.

**3. Удержание клиента в экосистеме T‑Банка**  
Пользователь уже видит **T‑Invest** в koshel. Добавление дебетовых счетов T‑Банка делает приложение «домашним» для клиента банка и снижает мотивацию уходить к сторонним агрегаторам.

**4. Пилот Open Finance**  
ЦБ РФ развивает стандарты Open API для физлиц. koshel готов стать **партнёрским PFM** в пилоте — с готовой инфраструктурой согласий, серверным хранением токенов и UI подключений.

**5. Качество аудитории**  
Пользователи PFM — вовлечённые в финансы клиенты: они следят за тратами, инвестируют, открывают вклады. Это целевая аудитория для премиальных продуктов банка.

**6. Без «серых» методов**  
Мы **не используем** парсинг интернет-банка и хранение паролей. Только официальный API и явное согласие — в интересах репутации и безопасности банка.
