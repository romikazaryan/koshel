# Подключение T-Invest к koshel

## Что получите

- **Капитал** — акции и ETF из портфеля T-Invest (количество + оценка в ₽)
- **Доходы** — дивиденды и купоны
- **Расходы** — комиссии брокера

Покупки и продажи бумаг **не** попадают в «Расходы» — это не траты, а перераспределение капитала.

---

## Шаг 1 — выпустить read-only токен

1. Откройте приложение **T-Invest**
2. **Настройки** → **T-Invest API**
3. **Выпустить токен** → **«Только чтение»**
4. Скопируйте токен — он показывается **один раз**

Инструкция: https://developer.tbank.ru/invest/intro/intro/token

---

## Шаг 2 — подключить в koshel

1. **Профиль** → **Банки и подключения**
2. Вкладка **Брокеры** → **T-Invest** → **Подключить**
3. Вставьте токен → **Подключить и синхронизировать**
4. **Финансы** → **Капитал** — позиции из портфеля

---

## Deploy (разработчик)

```bash
supabase functions deploy tinvest-connect
supabase functions deploy tinvest-sync
```

Миграции: `20260607100000_financial_connections.sql`, `20260607120000_tinvest_integration.sql`, `20260607130000_financial_secrets_service_grant.sql`

---

## Ошибка SSL / сертификата

T-Invest API использует сертификаты **НУЦ Минцифры РФ**. Запросы к API идут **через сервер koshel** (Supabase Edge), не напрямую с телефона — в Edge встроены российские корневые сертификаты.

Если видите ошибку про `certificate` или `UnknownIssuer` — обновите приложение и убедитесь, что задеплоены актуальные `tinvest-connect` и `tinvest-sync`.
