## О проекте

**koshel** — мобильное приложение учёта личных расходов (название только латиницей).

**Цель продукта:** быстро фиксировать траты (ручной ввод, голос, чек) и получать AI-анализ месяца.

**Перспектива (важно):** привязка **онлайн-банков через API** (не импорт выписок — пользователю это не подходит). Сейчас заложены аккаунты, `user_id`, RLS, поле `source` (`bank` — зарезервировано).

**Путь к проекту:** `/Users/romik/Desktop/koshel`

**Supabase:** `mahtodsjuqpazvvdegvu` → `https://mahtodsjuqpazvvdegvu.supabase.co`

**Стек:** Expo SDK 56, React Native, TypeScript, Supabase (Auth, DB, Edge Functions), Yandex GPT + Vision.

**Запуск на iPhone:** development / release build (`expo run:ios --device`). Expo Go **не подходит** (SDK 56). Для повседневной работы пользователь использует **Release** (`npm run ios:release`) — без Metro.

## Известные проблемы / ограничения

| Проблема | Статус |
|---------|--------|
| Чек OCR может быть медленным (облако Yandex) | Сжатие фото добавлено; дальше — только оптимизация на сервере |
| Телефон/SMS — нет Twilio | UI есть, SMS не настроен |
| Письмо Confirm email + localhost | Confirm email выкл.; deep link на будущее |
| Metro / dev client на iPhone | Используем Release build |
| Старые расходы без `user_id` | Не видны после миграции auth (ожидаемо) |
| Напоминания о долгах (`expo-notifications`) | Нужна **нативная пересборка** `npm run ios:release` после добавления плагина |
| День 31 в феврале / коротких месяцах | Напоминание срабатывает в последний день месяца (поведение iOS) |
